# 使用邮箱

## 创建邮箱

打开邮箱页面，选择**创建邮箱**。你可以选择：

- **前缀**——可选。留空则获得随机地址。前缀会转为小写，`@` 或连续的点号等字符
  会被拒绝。
- **域名**——为你的账号启用的收件域名之一。
- **有效期**——1 小时、1 天、3 天或永久。

地址会在创建之前显示，因此你可以先复制再决定是否创建。重复创建同一地址时，会用
当前语言提示"名称已被占用"。

## 阅读邮件

邮箱列表显示每个邮箱的总数和未读数，并可按域名筛选。打开一封邮件会把它标记为
已读，未读计数减一。公开分享页面永远不会改变所有者的已读状态。

打开邮箱时，页面每 30 秒用增量游标轮询新邮件。标签页隐藏时轮询暂停，回到页面
后恢复。手动刷新会更新计数和第一屏消息；已经加载过的较早页面可能仍保留旧内容，
直到你重新加载。

## 分享邮箱或单封邮件

整个邮箱和单封邮件都可以用链接分享：

- **邮箱分享**——`https://<host>/shared/<token>`
- **邮件分享**——`https://<host>/shared/message/<token>`

每个分享都有有效期。创建时选择时长，或用 `0` 创建永久分享。已过期的分享会被
拒绝——在正好等于过期时间戳的时刻也不例外。分享列表支持分页，单个链接也可以
再次删除。

## 批量删除

在列表中每批最多选择 **40** 个邮箱，选择**删除所选**并确认。删除邮箱会同时移除
它收到和发出的邮件以及全部分享链接，且无法撤销。每日发信配额不会退还。

有几条值得知道的规则：

- 选择状态在翻页后依然保留，因此可以跨多页挑选邮箱，**清除选择**可重置。
- 切换域名筛选会清空选择。
- Catch-all 邮箱永远不参与批量选择。
- API 只删除属于你、尚未过期、且不是 Catch-all 的邮箱。若批次中有一个邮箱未通过
  检查，整批都会失败——不会出现部分删除，选择状态保留以便重试。

## 限制

皇帝设置 `MAX_EMAILS`，即非皇帝账号最多拥有的活跃邮箱数，默认 30。皇帝不受限
制。无效的值在保存时会被拒绝。

## 发信

拥有*公爵*或*骑士*角色的账号可以通过 Resend 从邮箱发信，受每日配额限制。配置
方式见[站点设置与发信](/getting-started/settings)。
