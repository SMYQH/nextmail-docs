# 常见问题

## 部署

**我需要哪个 Cloudflare 套餐？**
: 推荐使用付费的 Workers 套餐。密码哈希使用 bcrypt，异步运算可能超出免费版每请求
10 毫秒的 CPU 预算。不要为了迁就免费版而削弱 bcrypt 强度——如果你只用 OAuth 登录，
或者站点仅供个人使用，可以忽略这一点。

**可以在 Windows 上部署吗？**
: Next.js 开发、lint 和单元测试在 Windows 上可用。请在 Linux（或 WSL）中用
Node.js 24 和全新的 `npm ci` 构建 OpenNext Worker——不要复用 Windows 的
`node_modules`。

**部署脚本中途停住了怎么办？**
: 部署不是事务。检查哪些步骤已完成（D1、KV、Secrets、Workers），然后重新运行
脚本；已存在的资源会被复用。

**我需要自己创建 DNS 记录吗？**
: 不需要。使用 `CUSTOM_DOMAIN` 时脚本会采用 Worker 自定义域名，由 Cloudflare 自动
配置 DNS 和证书。普通的 Worker Route 只匹配已代理的 DNS 流量，不能替代它。

## 收信

**邮件一直收不到。**
: 检查域名是否在站点设置中列出、Cloudflare 的 Catch-all 规则是否指向
`email-receiver-worker`，以及该 Zone 是否由 Cloudflare 托管。详见
[邮箱域名与邮件路由](/getting-started/email-domain)。

**Catch-all 开关一直转圈。**
: 打开**路由规则** → **目标地址**，手动绑定一个邮箱。

**我能收到从未创建过的地址的邮件吗？**
: 可以——这正是 Catch-all 邮箱的用途，而且可以按域名启用。

**我重命名了 Catch-all 邮箱，邮件丢了吗？**
: 没有。邮箱保留它的 ID 和已有邮件，只有地址发生变化。

## 账号与权限

**我怎么成为站点所有者？**
: 登录后在个人中心页面使用**初始化站点所有者**。第一个完成确认的账号成为皇帝。
详见[角色与权限](/getting-started/roles)。

**能有两位皇帝吗？**
: 不能。站点只支持一位皇帝，界面会拒绝提升第二个人。

**为什么我创建不了 API Key？**
: API Key 需要公爵或皇帝角色。平民和骑士没有该权限。

## 邮箱

**我能创建多少个邮箱？**
: 非皇帝账号 `MAX_EMAILS` 个，默认 30。皇帝不受限制。

**删除邮箱会发生什么？**
: 它的邮件和分享链接也会被删除，且无法撤销。每日发信配额不会退还。

**我能一次删除 100 个邮箱吗？**
: 批量操作每批最多 40 个。如果批次中有一个邮箱未通过检查（不属于你、已过期，或
是 Catch-all 邮箱），整批失败，什么都不会被删除。

## 发信

**什么都发不出去，也看不到发送按钮。**
: 必须在 Resend 配置中为该域名启用发信，并且你的角色需要*发送邮件*权限和配额。

**发信配额什么时候重置？**
: 在 UTC 00:00。

**删除邮箱会退还配额吗？**
: 不会。配额按用户按天计算。

## API 与 Webhook

**API 返回 503。**
: 没有配置收件域名。设置 `EMAIL_DOMAINS`（或让部署从 `EMAIL_DOMAIN` 初始化）。

**创建 API Key 时 API 返回 409。**
: 该名称已被你的某个 Key 占用——即使那个 Key 已禁用或已过期。换一个名字。

**我的 Webhook 没有被投递。**
: 目标主机必须在 `WEBHOOK_ALLOWED_HOSTS` 中，URL 必须是 HTTPS 且不含凭据、片段
或非标准端口，并且 Webhook 已启用且已保存。

**Webhook 投递是恰好一次吗？**
: 不是。投递最多重试三次，因此同一个 `messageId` 可能到达多次。请按 `messageId`
去重。
